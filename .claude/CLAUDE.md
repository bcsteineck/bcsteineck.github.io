# Portfolio Project

This is my personal portfolio website.

## Goals
- Showcase my work and experience.
- Prioritize clean design and accessibility.
- Favor simplicity over flashy effects.
- Maintain a premium, minimal aesthetic.

## Tech Stack
- React
- TypeScript
- Vite
- React Router
- Sass

## Design Principles
- Scandinavian-inspired minimalism.
- Black, white, and subtle grays.
- No glassmorphism.
- No gradients unless explicitly requested.
- No unnecessary animations.
- Keep typography readable.
- Preserve generous whitespace.

## Code Philosophy
- Prefer readable code over clever code.
- Don't introduce dependencies unless requested.
- Don't refactor unrelated files.
- Don't rename files or move components without permission.
- Don't change styling outside the requested task.
